>_  CryptIt! - 2022
A very basic GUI Python application for encrypting and decrypting text using Caeser or ROT13 ciphers. Built with Tkinter, it offers a user-friendly way to experiment with basic cryptography technqiues.

Features:

  • Encrypt and decrypt text using Caeser Cipher.
  • Encrypt and decrypt text using ROT13 Cipher.
  • User-friendly GUI built with Tkinter.
  • Real-time output display.
  • Adjustable shift value for Caeser Cipher.
